# Data Sources

## Files required for training

### `gene_labels.tsv`
Binary labels for all 15 target identification tasks.
Columns include `Gene_Symbol` and one column per task (0/1).
Contact the authors or refer to the paper for access.

### `gene_features.tsv`
482-dimensional structured biological features per gene.
Derived from the following public databases:

| Source | Features |
|--------|----------|
| ExAC / gnomAD | Population genetics (pLI, missense Z-score) |
| PHAROS / IDG | Target development level, ligand counts |
| CTDbase | Chemical-gene interaction counts |
| STRING | PPI network degree, clustering coefficient |
| InterPro | Domain annotations |
| UniProt | Subcellular localisation, PTM sites |
| DepMap | CRISPR essentiality scores |
| Open Targets | Genetic association scores |

Contact the authors or refer to the paper for access.

## Files generated by the pipeline

### `gene_summaries.tsv`
Gene Symbol + NCBI Entrez summary text.
Generated by `scripts/fetch_gene_summaries.py`.

### `features_llm_structured_scores.csv`
12-dimensional explicit therapeutic attribute scores per gene.
Generated by `llm/preprocess.py --mode scores`.

### `features_llm_embedding.csv`
1536-dimensional implicit LLM embeddings per gene.
Generated by `llm/preprocess.py --mode embeddings`.

### `prior_task_summary.csv`
LLM-estimated class prior π for each of the 15 tasks.
Generated by `llm/preprocess.py --mode priors`.
